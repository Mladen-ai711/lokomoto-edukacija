# Lokomoto edukacija

Takmičarska landing stranica za dvodnevnu praktičnu edukaciju „Procena i
rehabilitacija bola u donjem delu leđa“ u Lokomoto Centru.

Stranica je statička i automatski se objavljuje na GitHub Pages nakon svake
izmene na `main` grani.

## Struktura

- `index.html` — sadržaj stranice
- `styles.css` — kompletan vizuelni sistem i responsive stilovi
- `images/` — optimizovane fotografije
- `.github/workflows/deploy-pages.yml` — automatsko objavljivanje
